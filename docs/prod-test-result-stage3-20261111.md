### H. 壊れたときの挙動
- H1(開発用の画面): 代役のサーバーで、閲覧の権限の確認だけを通し、ほかの通信を切った。トップは各欄に「〜を読み込めませんでした。」と出る(Works・Skills は末尾に英語の「TypeError: Failed to fetch」が付く)。作品詳細は「TypeError: Failed to fetch」と「‹ Works 一覧へ戻る」だけで、読み込めないことが日本語で分からない。すべての通信を切ると「閲覧権限を確認できませんでした。」と出る。
- H2(本番): `/no-such-page` は Next.js 既定の英語の 404 で、トップへ戻る手段が無い。存在しない作品 ID では、オーナーのログインで「Cannot coerce the result to a single JSON object」、ゲストのログインで短い ID を渡すと「invalid input syntax for type uuid: …」と出る。どちらも英語のエラー文で、「‹ Works 一覧へ戻る」はある。
- H3(本番): 2026-11-10 15:14(UTC)に 894c880d を開いたまま置き、80 分後に下までスクロールした。画像 17/17 が表示され、欠け 0、ログイン画面に戻らない。開いた時点で読み込み済みだったのは 11 枚で、残り 6 枚は 80 分後に初めて読み込まれた(期限切れの後でも新しく発行される)。
- H4: オーナーが実施し、基準どおりと報告(2026-11-11)。
- H5(開発用の画面): 通信をすべて切って送ると「送信できませんでした。時間をおいて…」と YOUTRUST への案内が出て、入力は残る。通信の問題だとは読み取れない。

### I. 問い合わせフォーム
