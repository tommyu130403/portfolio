## 用語

| 用語 | 意味 |
|---|---|
| 必須 / 推奨 | 必須 = 1 件でも不合格なら公開しない。推奨 = 不合格でも、オーナーが内容を見て「このまま公開 / 直してから公開」を決められる |
| 合格(注記) | 合格としたが、計画の手順の一部を省いた・代わりの方法で見たなど、但し書きがあるもの |
| 開発用の画面 | 手元で動かした確認用のサイト。本番のデータや公開サイトには触れない |
| 低速 4G | スマホの回線が混んでいるときを想定した、遅い通信の条件 |
| 共有用の情報 | URL を LINE などに貼ったときに出る題名・説明・画像。サイトの HTML の中に書いてある |
