| Before / After | ① `::: beforeafter` ② `grid`＋`card Before:`＋`card tone=accent After:` ③ 表「変更前｜変更後」 | ① 894c ② 2041 ③ 0d52 |

## 2. 対応表（合意済み・2026-11-03）

見本: 2026-11-03 に実際の本文部品で描画して確認（P1〜P10）。プレビュー: https://claude.ai/artifact/CXn8jasXubJgiXebTqLxso

原則: **1 種類の情報 = 1 つの見せ方**。記法は既存のものだけを使う。

| # | 情報の種類 | 正しい見せ方 | 使わない見せ方 |
|---|---|---|---|
| P1 | 目的・ゴール（KGI / KPI も同じ） | `::: grid cols=2 gap=4` ＋ `::: card 目的` / `::: card ゴール`。見出しは `## 目的とゴール` の1つだけ | `## 目的` `## ゴール` の見出し分け |
| P2 | 対象外 | 見出し名は `## スコープ外`、中身は `- ` 箇条書き | 「やらないこと」表記 |
| P3 | 進め方（段階・時系列） | `::: flow 進め方 highlight=0`。手法・時期を添えるときだけ `::: figure 進め方` で包み、flow の直下に3列表 | 手順を文章や番号リストで書く |
| P4a | Before / After：手順・導線の変化 | `::: beforeafter`（矢印でつながった手順を上下に並べる） | 手順の変化をカードの文章で書く |
| P4b | Before / After：状態・考え方の変化（文章で説明する） | `::: grid cols=2 gap=4` ＋ `::: card Before` ／ `::: card tone=accent After`（After だけ強調色） | 手順を矢印つきの文章でカードに書く |
| P4c | Before / After：対応する変更点が 3 つ以上 | 2 列表「変更前｜変更後」 | 変更点ごとに図を並べる |
| P5 | 並列する観点（2〜3 個） | `::: grid cols=N gap=4` ＋ `::: card`。強調の `tone=accent` は **1 図につき 1 枚**（結論・課題・After のどれか） | accent を複数枚 |
| P6 | 一覧・定義（ラベル＋説明） | 2 列表。見出しを付けたいときは `::: figure 見出し` で包む | 箇条書きで「ラベル: 説明」 |
| P7 | 図版のまとまり（flow / bars / 表 / grid / 画像群） | `::: figure 見出し | 補足文` で包む。例外は P1・P3 単独・mockup・workcard | 見出しなしで裸置き |
| P8 | 出典 | 図版の直後に `::: caption 出典: ○○`。補足もあるときは「補足文。出典: ○○」の1行 | 出典を本文段落に書く |
| P9 | 画面写真 | 実機の画面 → `::: mockup phone/laptop`。スライド・図・資料 → `![キャプション](url)` | 画面写真を `![]` で裸置き |
| P10 | flow の強調 | 自分が担当した段・今回変えた段があるときだけ `highlight=N`。プロセス紹介は `highlight=0` | 意味のない強調 |
| P11 | 他作品への言及 | `::: workcard id=<uuid>` | 本文中のリンクだけ |
