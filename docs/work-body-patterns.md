# work 本文の書き方（同じ種類の情報は同じ見せ方）

- 正: `docs/requests/20261103-work-body-pattern-unify.md` §2 の対応表（2026-11-03 合意）
- 使える記法の一覧: `components/WorkMarkdown.tsx` の冒頭コメント
- 原則: **1 種類の情報 = 1 つの見せ方**。記法は既存のものだけを使う。新しいブロック記法・部品は足さない

## 対応表

| # | 情報の種類 | 正しい見せ方 | 使わない見せ方 |
|---|---|---|---|
| P1 | 目的・ゴール（KGI / KPI も同じ） | `::: grid cols=2 gap=4` ＋ `::: card 目的` / `::: card ゴール`。見出しは `## 目的とゴール` の1つだけ | `## 目的` `## ゴール` の見出し分け |
| P2 | 対象外 | 見出し名は `## スコープ外`、中身は `- ` 箇条書き | 「やらないこと」表記 |
| P3 | 進め方（段階・時系列） | `::: flow 進め方 highlight=0`。手法・時期を添えるときだけ `::: figure 進め方` で包み、flow の直下に3列表 | 手順を文章や番号リストで書く |
| P4a | Before / After：手順・導線の変化 | `::: beforeafter`（矢印でつながった手順を上下に並べる） | 手順の変化をカードの文章で書く |
| P4b | Before / After：状態・考え方の変化（文章で説明する） | `::: grid cols=2 gap=4` ＋ `::: card Before` ／ `::: card tone=accent After`（After だけ強調色） | 手順を矢印つきの文章でカードに書く |
| P4c | Before / After：対応する変更点が 3 つ以上 | 2 列表「変更前｜変更後」 | 変更点ごとに図を並べる |
| P5 | 並列する観点（2〜3 個） | `::: grid cols=N gap=4` ＋ `::: card`。強調の `tone=accent` は **1 図につき 1 枚**（結論・課題・After のどれか） | accent を複数枚 |
| P6 | 一覧・定義（ラベル＋説明） | 2 列表。見出しを付けたいときは `::: figure 見出し` で包む | 箇条書きで「ラベル: 説明」 |
| P7 | 図版のまとまり（flow / bars / 表 / grid / 画像群） | `::: figure 見出し \| 補足文` で包む。例外は P1・P3 単独・mockup・workcard | 見出しなしで裸置き |
| P8 | 出典 | 図版の直後に `::: caption 出典: ○○`。補足もあるときは「補足文。出典: ○○」の1行 | 出典を本文段落に書く |
| P9 | 画面写真 | 実機の画面 → `::: mockup phone/laptop`。スライド・図・資料 → `![キャプション](url)` | 画面写真を `![]` で裸置き |
| P10 | flow の強調 | 自分が担当した段・今回変えた段があるときだけ `highlight=N`。プロセス紹介は `highlight=0` | 意味のない強調 |
| P11 | 他作品への言及 | `::: workcard id=<uuid>` | 本文中のリンクだけ |

## 書き方サンプル（コピペ用の最小例）

### P1 目的・ゴール

```
## 目的とゴール

::: grid cols=2 gap=4
::: card 目的
新規登録までの離脱を減らす
:::
---
::: card ゴール
登録完了率 ○% → ○%
:::
:::
```

### P2 対象外

```
## スコープ外

- 決済まわりの改修
- 管理画面の変更
```

### P3 進め方

単独で置くとき:

```
::: flow 進め方 highlight=0
- 調査
- 設計
- 検証
:::
```

手法・時期を添えるとき:

```
::: figure 進め方
::: flow highlight=0
- 調査
- 設計
- 検証
:::

| 段階 | 手法 | 時期 |
| --- | --- | --- |
| 調査 | インタビュー | 1 か月目 |
| 設計 | プロトタイプ | 2 か月目 |
| 検証 | A/B テスト | 3 か月目 |
:::
```

### P4a Before / After：手順・導線の変化

```
::: beforeafter 導線 | 登録導線の一本化
before: トップ → 診断 → [!別サイトへ遷移] → 登録
after: トップ → [+その場で登録] → 完了
note: 遷移を 1 回減らした
:::
```

### P4b Before / After：状態・考え方の変化

```
::: grid cols=2 gap=4
::: card Before
担当者ごとに判断がばらついていた
:::
---
::: card tone=accent After
共通の基準で判断できるようになった
:::
:::
```

### P4c Before / After：変更点が 3 つ以上

```
| 変更前 | 変更後 |
| --- | --- |
| 入力 8 項目 | 入力 4 項目 |
| 確認画面あり | 確認画面なし |
| PC のみ | スマホ対応 |
```

### P5 並列する観点

```

::: card 観点A
説明
:::
---
::: card 観点B
説明
:::
---
::: card tone=accent 結論
説明
:::
:::
```

### P6 一覧・定義

```
::: figure 用語の定義
| 用語 | 説明 |
| --- | --- |
| KGI | 最終的に目指す指標 |
| KPI | 途中経過を測る指標 |
:::
```

### P7 図版のまとまり

```
::: figure 施策の効果 | 導入前後の比較
::: bars base=1.0 max=1.4
- 登録率 | 導入後 | 1.3 | 130% | up
:::
:::
```

### P8 出典

```
::: figure 施策の効果
（図版）
::: caption 出典: 社内レポート「2024 年度振り返り」
:::
```

補足もあるとき:

```
::: caption 2024 年 4 月時点の値。出典: 社内レポート
```

caption は figure の中、閉じる `:::` の直前に置く。これを対応表の「図版の直後」とみなす(見え方は同じ。既存の本文もこの置き方。2026-11-03 合意)。
