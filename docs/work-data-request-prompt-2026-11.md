## 依頼: ポートフォリオ掲載用に、前職の資料から 3 つの事実を集めてほしい

### 目的
個人のポートフォリオサイトに載せている作品 2 件の「成果」の節が、事実の裏付けが無く空いている。前職の資料から、載せてよい範囲の事実と画面を集めたい。

- 作品 B: キャリアチケットスカウトの「募集掲載機能」(2022年6月〜12月。企業が募集を掲載し、学生が応募できる機能)

### 集めてほしいこと
| ID | 内容 | 探す場所の例 |
| --- | --- | --- |
| A1 | 価値観マッチング機能で、最終的に確定してリリースした画面(学生側・企業側)。どの画面が最終版か | Figma のファイル・ページ、リリース告知、仕様書 |
| B1 | 募集掲載機能のユーザーヒアリングを実施したか。実施したなら、対象・人数・時期・わかったこと(要点 3 つまで) | ヒアリング計画書、議事録、調査レポート |
| B2 | 募集掲載機能の最終デザインと、リリース後の応募状況(応募があったか・傾向) | Figma、リリース後の振り返り資料、定例資料 |

### 成果物
次の表 1 つと、画面の書き出し画像。
| ID | 判定(見つかった / 一部 / 見つからない) | 事実(1〜3 行) | 出典(資料名・ページ・日付) | 社外に出してよいか(はい / いいえ / わからない) |

画面の書き出し(A1・B2)は PNG で、1 画面 1 枚。ファイル名は `pf-values-final-<画面名>.png` / `pf-posting-final-<画面名>.png`。

### 完了条件
- A1・B1・B2 の 3 行すべてに判定と出典がある
- 「見つからない」の行は、探した場所を書いてある

### 確かめ方
- 事実は資料の文面で確かめたものだけを書く。推測で埋めない
- 最終版かどうかは、資料に「確定」「リリース」などの記述がある場合だけ「最終版」とする

- 数値(応募数・率・売上など)は、資料に書かれていても表には書かず「数値あり(社外秘の可能性)」とだけ書く
- 実在の学生・企業担当者の氏名、メールアドレス、顔写真、企業名(自社以外)が写った画面は書き出さない。写る場合はぼかすか、その画面を外す
- 資料の文章を長くそのまま写さない(1 か所 1 行まで)
- 資料の編集・コメント・共有設定の変更をしない

### 止まる条件
- 資料にアクセスする権限が無い、または社外秘の表示がある資料だけしか見つからない → その時点で報告して止まる
- その資料をポートフォリオのために見てよいか(在籍時の取り決め・退職後の扱い)がわからない → 開く前に報告して止まる
- 上の表の「探す場所の例」をすべて探しても 3 項目とも見つからない → 探した場所を報告して止まる
