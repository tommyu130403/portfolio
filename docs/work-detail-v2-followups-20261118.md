## 3. トークンとスタイルガイド

- PR1・PR2 で増えたトークンは `--container-wide`(1120px)だけ。表には載っていたが説明文に無かったので追記した(`app/styleguide/StyleguideLayout.tsx` の Container 節)。`WORK_FIGURE_TONE` は表と意味の説明が揃っている。
- v2 のコードに色の直書き(#xxxxxx・rgb)は無い。

## 5. 確認事項

- 年表の帯が範囲の端を越える件(ed9e・177a): 計測では帯の右端は枠の右端と一致(差 0.01px 未満)で、はみ出しは無い。ed9e は本文の期間の終わりが `2025-04-01` で範囲の終わりと同じため、帯が端まで届いて見える。描画の修正は不要。気になる場合は本文の終わりを `2025-03-31` にする(本番本文の変更なので別途)。
- デザイン監査(design-auditor・894c / ed9e / 177a・1440 / 390px): 深刻度 3 以上なし。深刻度 2 は次の 6 件(2 以外はこの PR では直していない)。
  1. 上部に固定されたパンくず・前後ボタンに背景が無く、本文の文字と重なる(全幅)→ **見送り**: 2026-11-19 に「地を敷く」案と比べ、オーナーが現状を選んだ
  2. 体制図のドット数と「計 N 名」が兼務のある作品で一致しない(説明が図に無い)→ **対応済み**: この PR で合計の横と読み上げに「（自分は 1 名で計上）」を追加
  3. 体制図のメンバーのドット(灰)が背景に対して 2.66:1 で、図形の基準 3:1 未満 → **対応済み**: v2 だけ、ほかのメンバーを中抜きの丸(線 fg-muted・5.9:1)に。自分(ミントの塗り)と色だけでなく形でも見分けられる(監査の追加指摘を受けたオーナー判断 2026-11-19)。`WORK_FIGURE_TONE.dotOther` を変更、v1 は fg-caption の塗りのまま
  4. ツールの小アイコンの名前がマウスを重ねたときしか出ず、キーボード・タッチでは分からない → **見送り**: 名前を常に出す案と比べ、オーナーが現状を選んだ
  5. パンくずの「Works」と「01 / 12」の文字色が 2.96:1(文字の基準 4.5:1 未満。キャプション色 #5D5D69 の承知済みの判断が及ぶなら 1)→ **見送り**: キャプション色はオーナー承知済み(2026-11-13)
  6. 1440px の年表で、11〜1 月の節目 4 つが近く、ラベルが 3 段に重なって読みにくい(ed9e)→ **対応済み**: v2 だけ、各ラベルから点・帯へ細い引き出し線(border-light)を引く。線が上の段の文字を横切らないよう、ラベルの下に地の色を敷いた。段の振り分けは変えていない
- 深刻度 1: 目次の項目数が PC とスマホで違う・目次の現在地の切替が遅い・前後カードの右端が本文の列より広い・タグの文字 10px・894c のスマホの年表に日付の無い行が 1 つ・画像拡大ボタンの名前がすべて同じ。
