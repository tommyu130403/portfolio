# プロジェクト概要

働きながら転職活動をする人に向けた企業情報プラットフォームFactBoardの立ち上げと運用に関わった。
企業の「正しい情報」を「効率的」に集められることを提供価値とし、口コミメディアとは逆のポジションを取ったメディアとしてリリースされた。
企業のWebサイトや口コミサイトと並行して使われる「企業情報・転職活動のセカンドオピニオン」を目指す。2025年9月にコンセプト検討を始め、2026年3月にリリースした。

# 役割

リードデザイナーとしてこのプロジェクトのデザイン品質定義や要件整理、UIの最終意思決定を行った。
主にデザインは現場のメンバーが担当。

# 背景と課題

転職を検討している求職者は、気になる企業の情報をしっかり集めて比較検討をしたいが、働きながらの転職では、企業分析や面接対策に十分な時間を割けない。口コミは個人的な意見も多く、当事者だけの発信では信頼性に欠けるため。質の高い情報を確実に効率よく収集したいというニーズがあった。

## ターゲット

国内での就業を検討する転職者全般である。ボリューム層は25〜34歳と35〜44歳である。

## スコープ外

- 個人の主観を含む口コミは集めない
- ブランディング目的の企業イメージ広告は扱わない
- 広告に頼らず、自然検索を中心に集客する
- 企業・一般ユーザーへの課金は当面見送る

### 送客機能の企画

診断、AI相談、転職Q&Aを比較した。AI相談は送客が弱く、Q&Aは大手Q&Aサービスと正面から競合するため除外した。書類選考の通過チェックは独自情報になる企業が限られるため、既存データだけで計算できる相性診断に差し替えた。

::: figure 送客機能の候補 | 独自情報の有無と競合状況で絞り込んだ
::: flow highlight=0
- 診断 / AI相談 / Q&A
- AI相談は送客が弱い
- Q&A は大手と正面競合
- 通過チェックは独自情報が限られる
- 既存データで計算できる相性診断
:::
:::

### ロゴとブランド

機能性を重視した案を9割、権威性を重視した案を1割とする方向で、サンセリフ体のロゴに決めた。ブランドカラーはターコイズ(#14B3B3)とブラック(#292929)である。2026年1月にサービス名を決め、2〜3月にロゴを確定し、3月にロゴガイドラインv1.0として定めた。

# 成果

## これまでの成果

- サービス名、ロゴ、ロゴガイドラインを確定した
- コンテンツと送客導線を段階的にリリース

## 現在の課題

- 中間コンバージョン数の伸びが訪問数の伸びに追いついておらず、下期の重点課題である
- 記事内の導線を想定の最大数まで置いても、LPへの遷移率は目標に届いていない
- 独自情報がないとSEOが不安定になる。検索エンジンのアップデートで一次情報の評価が強まり、テンプレートで量産したページのリスクも高まった。そのため、売上計画をSEOだけで組まない方針である
- 送客機能の入力受付テストは日程を再検討中
