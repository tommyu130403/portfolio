# プロジェクト概要
::: summary
lead: 働きながら転職活動をする人に向けた企業情報メディアFactBoardの立ち上げから運用まで、デザイン側のリードを担った。
problem: 働きながらの転職では企業分析に十分な時間を割けず、口コミは個人的な意見も多く信頼性に欠ける。
action: コンセプト検討から戦略の仮説、コンテンツ・機能設計、サービス名・ロゴまでを進めた。
result: 2026年3月にリリースした。中間コンバージョン数の伸びは課題である。
:::

企業の「正しい情報」を「効率的」に集められることを提供価値とし、口コミメディアとは逆のポジションを取った。
企業のWebサイトや口コミサイトと並行して使われる「企業情報・転職活動のセカンドオピニオン」を目指す。2025年9月にコンセプト検討を始め、2026年3月にリリースした。

# 役割
リードデザイナーとして、デザイン品質の定義、要件整理、UIの最終意思決定を行った。
デザイン制作は主に現場のメンバーが担当した。ロゴ制作のコミュニケーションデザイナーと、社内の記事編集局のライターも加わった。

::: team 体制
- 意思決定・進行 = Product, Project
- デザイン = Designer
- 開発 = Engineer
- 記事編集 = Other
:::

# 背景と課題
転職を検討している求職者は、気になる企業の情報をしっかり集めて比較検討をしたいが、働きながらの転職では、企業分析や面接対策に十分な時間を割けない。口コミは個人的な意見も多く、当事者だけの発信では信頼性に欠ける。そのため、質の高い情報を確実に効率よく集めたいというニーズがあった。

::: grid cols=2 gap=4
::: card 目的
ミッションは「転職者にベストなキャリアを提供する」こと。選択肢の全容を知り、手間をかけずにキャリアを絞り込め、合格の可能性を高められる状態をつくる
:::
---
::: card ゴール
訪問数・コンバージョン数・掲載社数の目標を、2028年3月まで段階的に設定した。まずは黒字化を目指す
:::
:::

## ターゲット

国内での就業を検討する転職者全般である。利用者の中心は25〜34歳と35〜44歳である。

## スコープ外

- 個人の主観を含む口コミは集めない
- ブランディング目的の企業イメージ広告は扱わない
- 広告による集客
- 企業・一般ユーザーへの課金は当面見送る

- キャリア診断への導線の共通化
- 埋め込みフォーム型の導線
- サイトトップのリニューアル
- CMSの一括編集
- 企業に紐づかない記事

機能性9割・権威性1割の印象を目指す方向で、サンセリフ体のロゴに決めた。ブランドカラーはターコイズ(#14B3B3)とブラック(#292929)である。2026年1月にサービス名を決め、2〜3月にロゴを確定し、3月にロゴガイドラインv1.0として定めた。

::: card tone=accent 今後の方針
