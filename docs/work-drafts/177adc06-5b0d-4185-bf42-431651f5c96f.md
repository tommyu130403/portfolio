# プロジェクト概要

FactBoardは、働きながら転職活動をする人に向けた企業情報プラットフォームである。企業の「正しい情報」を「効率的」に集められることを提供価値とする。口コミメディアとは逆のポジションを取り、企業のWebサイトや口コミサイトと並行して使われる「企業情報・転職活動のセカンドオピニオン」を目指す。2025年9月にコンセプト検討を始め、現在も進行中である。

# 背景と課題

## 背景

転職は人生に直結する重要なイベントである。「失敗したくない」求職者は、気になる企業の情報をありったけ集めたい。しかし働きながらの転職では、企業分析や面接対策に十分な時間を割けない。口コミは個人的な意見も多く、当事者だけの発信では信頼性に欠ける。

## 目的とゴール

::: grid cols=2 gap=4
::: card 目的
ミッションは「転職者にベストなキャリアを提供する」こと。選択肢の全容を知り、受動的にキャリアを絞り込め、合格の可能性を高められる状態をつくる
:::

:::

## ターゲット

国内での就業を検討する転職者全般である。ボリューム層は25〜34歳と35〜44歳である。グループの人材サービスへの送客を想定し、ビジネス職とIT専門職を優先する。

## スコープ外

- 個人の主観を含む口コミは集めない
- ブランディング目的の企業イメージ広告は扱わない
- 広告に頼らず、自然検索を中心に集客する
- 企業・一般ユーザーへの課金は当面見送る

### 送客機能の企画

診断、AI相談、転職Q&Aを比較した。AI相談は送客が弱く、Q&Aは大手Q&Aサービスと正面から競合するため除外した。書類選考の通過チェックは独自情報になる企業が限られるため、既存データだけで計算できる相性診断に差し替えた。「想定年収・難易度診断」と「相性診断」の2案を、入力受付テストで比較する計画である。

::: figure 送客機能の候補 | 独自情報の有無と競合状況で絞り込んだ
::: flow highlight=0
- 診断 / AI相談 / Q&A
- AI相談は送客が弱い
- Q&A は大手と正面競合
- 通過チェックは独自情報が限られる
- 既存データで計算できる相性診断
:::
:::

### ロゴとブランド

機能性を重視した案を9割、権威性を重視した案を1割とする方向で、サンセリフ体のロゴに決めた。ブランドカラーはターコイズ（#14B3B3）とブラック（#292929）である。2026年1月にサービス名を決め、2〜3月にロゴを確定し、3月にロゴガイドラインv1.0を定めた。

## 現在の課題

- 中間コンバージョン数は、ベースラインも成長率も訪問数と乖離しており、下期の重点課題である
- 記事内の導線を想定の最大数まで置いても、LPへの遷移率は目標に届いていない
- 独自情報がないとSEOが不安定になる。検索エンジンのアップデートで一次情報の評価が強まり、テンプレートで量産したページのリスクも高まった。そのため、売上計画をSEOだけで組まない方針である
- 送客機能の入力受付テストは日程を再検討中で、効果検証の結果はまだない
