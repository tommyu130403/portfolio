# プロジェクト概要
::: summary
lead: キャリアチケットスカウトの学生側プロダクト改善として、価値観で企業と出会える「価値観マッチング」機能の企画に加わり、デザインと実装を担った。
problem: 学生は「やりたいこと」を言語化できず就活の軸が定まらない。知名度のない企業のスカウトは開封すらされないことが多かった。
action: 既存スカウト機能の課題整理とアイデア出しで方針を決め、価値観を選択式で選び、企業は共感した価値観を選んでオファーする仕様に落とし込んだ。
result: 2022年3月に本番リリース。既存のスカウト体験に大きな悪影響を与えず、登録者数が増えた。
:::

キャリアチケットスカウトの学生側プロダクト改善として、価値観マッチング機能の企画に加わった。

# 背景と課題
## 背景
学生10名・企業5社へのヒアリングから、次の傾向が見えた。
- **自己分析そのものはニーズではない**
- **やりたいことがわからず不安**
- **情報が多すぎて企業探しに疲れ、就活の軸がない**

自己分析機能を拡充するだけでは、良い出会いまでの道のりが長い。知名度のない企業のスカウトは開封すらされないことが多かった。議論では、スカウトサービスか自己分析サービスか方針を定めるべきこと、競合に対する明確な優位性がないことも挙がった。

::: figure 課題の特定 | ニーズ調査から見えた、ターゲット(就活の早期層〜中間層)の共通点
::: grid cols=2 gap=4
::: card 気づき
周囲に就活のやり方を聞きながら自己分析も進めるが、時期の差はあれど「就活の軸」を持てないまま企業を探している
:::
---
::: card tone=accent 課題
企業を絞り込むための「やりたいこと・将来何がしたいか」を言語化できず、就活の軸が定まらない
:::
:::
::: caption 学生の初期接点となるサービスにして集客コストを下げるため、早期層〜中間層をメインターゲットとした。
:::

## 目的とゴール

::: grid cols=2 gap=4
::: card 目的
学生に「このプロダクトを使えば、自分に合う企業が楽に見つかりそう」と直感的に思ってもらうこと
:::
---
::: card ゴール
KGIはオファー承諾率(承諾数÷オファー受信数)、KPIは学生1人あたりの興味を持った企業数(興味を持った企業数÷登録数)とした。
:::
:::

## 仮説
- 学生の価値観(やりたいこと)が企業と一致していることが、学生の意思決定を変えるフックになる。
- 「自己分析」ではなく「価値観で就活」と訴求すれば、サービスへの期待が高まる。

## 機能設計
- 学生は4つの観点から各3つの価値観をチェックボックスで選ぶ。
- 企業は、最も共感した価値観を1つ選んでオファーを送る。

::: figure 学生側の体験 | 4つの観点で価値観を選ぶと、完了画面で「キャリアに対する考え方」のタイプがわかる
::: flow highlight=0
- 理想のチーム(どんなチームで働きたいか)
- なりたい人物像(どんな人になりたいか)
- 将来身につけたいこと
- 理想とする環境(働く上で理想とする環境)
- 完了(タイプ表示)
:::
:::

# 学び
β版で「自己分析ができることがスカウトサービスを利用する動機づけになる」という仮説を検証した。その結果から「就活の軸 → 価値観」という新しい仮説を立て、次の検証につなげられた。

::: card tone=accent 仮説を持ち続ける
常に仮説を持ってプロダクトを検証し続けることが、プロダクトの継続的な成長に欠かせないと認識した。
:::
