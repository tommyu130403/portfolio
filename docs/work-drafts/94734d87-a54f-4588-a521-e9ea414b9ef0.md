# プロジェクト概要

キャリアチケットスカウト(以下CTS)が立ち上げ期(0→1)から拡大期(1→10)へ移るにあたり、市場でCTSが提供すべき価値(ポジション)を明確にするプロジェクトを進めた。

取り組みの5段階のうち「サービスの価値定義」まで確定させ、プロジェクトは2023年9月に終了した。

# 役割

カスタマージャーニーマップ作成ワークショップの実施要項、有識者ヒアリングの事前共有資料と質問、価値定義フェーズの実施概要を作成し、ワークショップ運営の振り返りまで行った。

事業責任者・プロダクトマネージャーの2名が意思決定を担い、エンジニア3名・カスタマーサクセス2名が加わる体制。その中でプロジェクトマネージャーとリードデザイナーを兼ね、ワークショップの設計と進行を担った。

# 背景と課題

## 背景
CTSは2021年にリリースし、2022年12月に正規版の機能リリースを完了した。0→1の立ち上げ期を終え、1→10の拡大期に入るところであった。

## 課題
本プロジェクトは、事業責任者が3か年予算の作成にあたって立ち上げた。拡大の見込みを立てるには、CTSが提供しようとしている価値が本当にユーザーの課題解決になっているのか、なっているならなぜなのかを明確にする必要があった。

## 注力すべきターゲットのセグメント定義
企業側と学生側それぞれのペルソナ定義のためのワークショップを実施。「ユーザーの発言した事実そのままを記録する」を注意点に掲げ、ユーザーの行動は事実、感情は推測として書き分けた。
また、ワークショップには既存のユーザーの声(問い合わせ、録画、アプリレビュー、過去プロジェクトのヒアリング記録)を事前情報として投入した。

## サービスの価値定義

- 価値の定義と共通認識づくりでは、ユーザーのニーズを起点に、これまでの市場にない独自の価値を見つけることを重視した。そのため、リーンキャンバスやビジネスモデル・キャンバスではなく、バリュー・プロポジション・キャンバス(VPC)を採用した。
- バリュー・プロポジションを「ユーザーの真のニーズにフィットしていて、かつ自社だけが提供できる価値」と定義し、競合のスカウト型サービスと並べて差分を見た。
- 提供価値が自社のケイパビリティ(実現する力)を超えた場合は、「なくてはならないもの」と「あったらうれしいもの」に分ける、という判断ルールを置いた。

## 指標の設計

::: figure 定義した価値が使われているかを測る(UX指標の枠組みHEART) | 学生側アプリについて、観点ごとにゴール → シグナル → 指標を整理した

| 観点 | ゴール → シグナル | 指標 |
| --- | --- | --- |
| Happiness | 自分の興味の方向性がわかる → スカウトを承諾する・イベントに応募する | 承諾数・承諾率 |
| Engagement | 参加したいときに使う → 週2〜3回アプリを開く | DAU・MAU |
| Adoption | インターン参加のために登録する → 新規登録が増える | 新規登録数 |
| Retention | 興味の方向性を知るために使い続ける → プロフィール更新・他己分析の依頼 | 更新数・依頼数 |
| Task Success | 使いたいときに使える → 情報へのアクセスとチャットが滞りない | エラー頻度 |
