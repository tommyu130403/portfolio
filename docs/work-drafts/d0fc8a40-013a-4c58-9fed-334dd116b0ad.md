# プロジェクト概要
::: summary
lead: キャリアチケットスカウト正規版に、学生がインターン・説明会へ応募できる募集掲載機能を企画し、学生側をリリースした。
problem: 自己PRや学生時代に力を入れたことを準備中の学生は、何もアクションできず就活を始められなかった。
action: 仮説整理とヒアリング設計を経て、アプリの「見え方」を定義し、募集掲載を段階導入で加える計画を設計した。
result: 2022年12月に学生側をリリース。リリース後は応募が入り、2023年1月には伸びていた。
:::

キャリアチケットスカウト正規版の第2四半期施策として、学生向けの募集掲載(インターン・説明会)機能を企画した。自己PRや学生時代に力を入れたことを準備中の学生でも、企業と接点を持てる状態をつくる。

## 要件定義
- 既存機能の優先度を踏まえて導線を配置すること
- 募集掲載の情報を「価値観」という指標でも探せること

## プロダクトの「見え方(プロモーション)」の設計
募集掲載機能をどこに置くかを既存機能との優先度で決めるには、「プロダクトそのものの見え方」から考える必要があった。これまでは「スカウトがくるアプリ」として打ち出していたが、募集掲載機能を足すと「スカウトがくるアプリ + 応募ができるアプリ」になる。どのようなプロダクトとして認識してもらうべきかを改めて定義した。

::: card アプリとしての「見え方」
「スカウトがくるアプリ + 応募ができるアプリ」
= **企業と複数の接点を持つことができるアプリ**
:::

::: figure 段階導入の設計 | 既存ユーザーへの影響と工数を抑えるため、「何ができるアプリか」を3フェーズで更新する
::: flow highlight=1
- PHASE01 スカウト > 募集
- PHASE02 スカウト + 募集
- PHASE03 キャンパスアプリ
:::

| フェーズ | 位置づけとグローバルナビ |
| --- | --- |
| PHASE01(今回) | 自己理解できて企業と出会えるアプリ。既存の構成を変えず、募集掲載(イベント)だけを追加する。ナビ: プロフィール / 自己分析 / イベント / メッセージ |
| PHASE02 | 企業と出会える手段が複数あるアプリ。自分の意思で変わる情報を「マイページ」に集約する。ナビ: マイページ / イベント / メッセージ |
| PHASE03 | キャンパスアプリ(キャリア支援)。オフラインの経路から来た学生にも、何ができるかわかる。ナビ: マイページ / イベント / スカウト / メッセージ |

:::

## 学生側: 「価値観」でもイベントを探せる
学生自ら企業を探すとなると、知っている企業か、興味のある業界や業種のみとなってしまう。このサービスの強みは「自分が知らない企業との出会い = 価値観マッチング」にある。そこで、登録時に設定済みの価値観でもイベントを絞り込めるようにした。

::: figure 絞り込みの流れ | 価値観 → 職種・目的の順に候補が絞られる(画面上の件数)
::: flow highlight=0
- すべてのイベント 1034件
- 価値観を3つ選ぶ 112件
- 職種・目的で絞る 14件
:::

# 学び
主要な機能の追加だったため、学生の「何ができるアプリなのか」という認識や体験にずれが起きないよう、全体を設計する必要があった。

::: card tone=accent 機能を足す前に「見え方」を決める
機能の優先度は、プロダクトが何として認識されるかで決まる。段階導入は、その認識を壊さずに更新するための計画だった。
:::
